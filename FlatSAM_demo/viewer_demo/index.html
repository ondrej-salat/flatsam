FlatSAM viewer demo

Four windows show the same frame: the first pass FlatSAM, the ground truth with the SAM3 mask, the refinement pass FlatSAM and the baselines. Every layer can be hidden (checkboxes next to the windows). The address bar always holds a link to the current view (sequence, frame, hidden layers, warp overlay, zoom).

Keys

← →previous / next frame
Shift + ← →10 frames at a time
Spaceplay / pause
↑ ↓previous / next sequence of the list
Fstar the sequence
Pscreenshot of the four windows
0reset the zoom
?this help

Mouse

drag, scrollmove the zoomed windows (the mouse does not zoom; use + and −)
double-clickreset the zoom
edge of the list, bar above the graphsdrag to change the size; drag to the edge of the screen to hide the panel, click the tab at the edge to show it again
click in a graphgo to that frame (drag to scrub)

Buttons

Paper framejump to the frame shown in the paper (when the sequence has one)
ScreenshotPNG of the four windows with the numbers of the frame
RecordMP4 of the whole sequence, with the warp overlays that are on

Layers

Numbers

P@5, P@10, P@15 (%)share of frames with a corner error of at most 5, 10 or 15 pixels, per sequence, in the list on the left (choose the threshold above it)
Error, pxRMS distance of the four corners to the ground truth in this frame (table on the right)
IoUoverlap of the quadrilateral with the ground truth
Δrefinement pass minus first pass, in P@15 points

Windows

warp overlayin the ground-truth window: the first frame warped onto the current one by the first pass (green, half transparent), the pose with which the refinement pass rectifies the frame; switch it off under "Ground truth" in the layer table
graphsIoU with the ground truth per frame; the strip shows which branch the pose gate chose; grey areas have no ground truth; the line under the first two graphs also gives the number of keypoint inliers of the current frame
